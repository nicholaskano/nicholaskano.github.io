# Nicholas Kano Photography Portfolio

This folder is a standalone static website ready for GitHub Pages.

## Publish on GitHub Pages

1. Extract the ZIP.
2. Create a public GitHub repository named `photography-portfolio`.
3. Upload everything inside this folder, including `index.html` and the `photos` folder.
4. Open the repository's **Settings**, select **Pages**, and choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.

## Edit the bio

Open `index.html`, search for `My name is Nicholas Kano`, edit that paragraph, and save.

## Add or change photos

Place JPG files in `photos`, then update the matching gallery button in `index.html`. Keep filenames lowercase with no spaces for the simplest GitHub hosting.
